# Book Library – личная библиотека

## Description
Мобильное приложение для учёта книг в личной коллекции. Позволяет добавлять, редактировать, удалять книги, помечать прочитанное. Реализована многопоточность (Room + корутины), база данных SQLite, жесты (свайп для удаления), навигация между экранами. Проект полностью на Jetpack Compose.

## Installation
1. Клонировать репозиторий:  
   `git clone https://github.com/fpmi-pmvs2026/pmvs13-project-Emin0204.git`
2. Открыть проект в Android Studio (2023.1+)
3. Синхронизировать gradle файлы
4. Запустить приложение на эмуляторе или реальном устройстве (min SDK 24)

## Usage
- **Главный экран** – список всех книг. Свайп вправо для удаления, кнопка «Редактировать» для изменения.
- **Кнопка +** – переход на экран добавления новой книги.
- **Экран добавления/редактирования** – заполните поля и нажмите «Сохранить».
- После удаления появляется Snackbar с подтверждением.
